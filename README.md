# YTLiveRecorder

Public **installers and auto-update feed** for YTLiveRecorder (Electron + yt-dlp + ffmpeg).

| | |
|--|--|
| **Downloads / updates** | [Releases](https://github.com/liquidcryptid/yt-live-recorder/releases) |
| **In-app updates** | Help → Check for Updates (ships with 1.2.0+) |

Development happens in a separate private host. This GitHub repository is kept for **release assets** and `electron-updater` metadata (`latest.yml`, `latest-linux.yml`).

> Not affiliated with YouTube or Google.
